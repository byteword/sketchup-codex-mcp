# Extended model operations

The 0.6.0 bridge adds get_resources, manage_resource, component, create_geometry, edit_geometry, mirror_entities, configure_camera and scene. Consult installed tool descriptions for typed per-action options; the checkout's docs/EXTENDED_TOOLKIT.md records the complete request comparison and limitations.

- Use exact existing material/tag names from get_resources. Page with next_offset and restart after edits. Layer0 is protected. Tag deletion preserves geometry. purge_unused affects the whole model and needs an explicit confirm_model_wide flag; a request to clean one object does not imply a whole-model purge.
- Drawing PIDs/full paths remain separate from resource identifiers. SketchUp2019 definitions/materials/tags have no PIDs. definition_id is the returned model-session-local `definition:<entityID>` string. Never turn it into a drawing PID; rediscover after document switching.
- component:convert converts groups; replace accepts component instances and an existing definition; instantiate creates a new occurrence at a model-axis origin. Recursive definitions/glued targets are rejected. explode preserves children; erase deletes them. Returned paths can replace old paths.
- edit_geometry targets one direct child container plus explicit raw IDs belonging to its definition. Default is unique geometry. Make unique for independent edits, or explicitly set affect_all_instances=true to change a shared component definition for every occurrence. Shared groups still require uniqueness. Report this effect when relevant; do not silently choose shared editing for a request about one copy.
- Raw line/face deletion and vertex movement can change adjacent topology. Query child paths again afterward. A vertex move is addressed by edge_id and start/end. ConstructionPoints are guide points, not isolated mesh vertices. Raw grouping needs the complete connected surface, including boundary edges/adjacent faces.
- create_geometry makes an isolated group. Arcs use center, two endpoints+signed bulge, or start/through/end; segments controls precision. Bezier is a sampled Curve from control points, not a retained NURBS/control-point editor. Freehand uses provided points, not screen drawing.
- Offset is limited to convex planar loops without holes. Simplify dissolves selected matching untextured coplanar internal edges and checks area; it is not curved-mesh decimation. Sweep requires a closed profile and a perpendicular initial path. Revolution needs a profile in one half-plane through the axis. Mesh budgets and manifold postconditions apply.
- Scenes are camera-only for create/update/delete. Apply copies only the saved camera, without selecting a page or changing its other saved states. Full style/shadow/tag scene state is not supported. SketchUp2019 scene changes lack the geometry command's Undo guarantee; an uncertain scene result is unknown and must be inspected before another mutation.

After an update prefer sketchup_run_self_test(suite=all) when its schema supports suite. The fixed suite excludes scene mutation and model-wide purge; report those exclusions rather than calling them passed. Native installation checks remain distinct from development doubles.
