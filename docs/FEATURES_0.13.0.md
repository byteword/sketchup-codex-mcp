# 0.13.0 — SketchUp 툴바와 보조 정보창

SketchUp 확장은 연결 제어를 기본4버튼 툴바로 제공한다. 정보창은 처음에 생성하지 않고4번째 버튼을 눌렀을 때만 연다. 연결과 실행 권한은 시작 시 꺼져 있다. Probe의 데스크톱 GUI와 MCP의 --start-gui 옵션은 별개이며 이번 변경은 그 시작 정책을 바꾸지 않는다.

| 순서 | 버튼 | 상태 및 동작 |
|---|---|---|
|1|연결 / 연결 해제|회색: 연결 안 됨, 초록: 연결됨, 주황: 재연결 대기, 빨강: 연결 오류. 연결 중·대기 중 다시 누르면 연결/재연결을 중단하고 권한을 회수한다.|
|2|권한 부여 / 회수|회색 잠금: 사용자 제어, 파란 열린 잠금: 명령 실행 허용. 연결되지 않았을 때 비활성. 누를 때마다 현재 모델의 권한을 전환한다.|
|3|긴급 정지|현재 세션·모델에 진행 중인 작업이 있을 때 활성. 실행 권한을 회수하고 협력적으로 취소한다. 중지 요청 후 결과를 기다리는 동안 중복 클릭을 막는다.|
|4|추가 정보창|정보창 열기/닫기. 열려 있으면 체크 표시. 연결·클라이언트·모델·버전·권한·현재 작업·오류 및 Ping 확인을 제공한다.|

정보창의 X로 닫아도 연결과 권한은 유지된다. 연결을 끊으려면1번, 권한만 회수하려면2번을 누른다. 툴바를 숨겼다면 Extensions > SketchUp MCP > 툴바 표시로 복원한다. 같은 메뉴에도4개 명령이 있다. 다음 시작에는 SketchUp이 저장한 툴바 배치/표시 상태를 복원하며 정보창은 항상 닫힌 상태로 시작한다.

**구버전 표시 제한:** 아이콘 경로/색상 변경을 요청하지만2019/2020 네이티브 툴바에서 실행 중 이미지 교체가 적용되지 않을 수 있다. [2020 개발자 보고](https://forums.sketchup.com/t/refresh-model-info-dialog-in-ruby/135479/5)가 있으며 이 장비의 실제 화면은 아직 확인하지 못했다. 연결·권한의 선택 강조(MF_CHECKED)와 툴팁도 함께 갱신한다. 아이콘 자체의 RGB 전환까지 검증 완료한 것으로 해석하지 않는다.

## 긴급 정지의 범위

Ruby의20초 시험 작업, 처리 중인 실제 변경 명령, Probe의 현재 문서에 바인딩된 기법 작업을 표시한다. Probe는 마지막 heartbeat의 session_id/model_id에 일치하는 queued/running 작업만 보낸다. 다른 모델·다른 세션·모델에 연결되지 않은 오프라인 계산은 이 버튼의 대상이 아니다. 상태 갱신은 보통1초 이내이며 SketchUp UI가 바쁠 때 지연될 수 있다.

아직 모델에 전달하지 않은 Probe 계산은 취소한다. 취소와 native 제출의 경계를 같은 잠금에서 확인해 취소된 계산이 뒤늦게 제출되지 않게 한다. 이미 제출한 명령은 성공·롤백·결과 불명 등 실제 응답을 유지하고 자동 재실행하지 않는다.

**긴 SketchUp Ruby API 호출이 메인 스레드를 점유하면 버튼 클릭 자체가 호출 종료 후 처리될 수 있다. 강제 중단/프로세스 종료 또는 이미 완료된 변경의 자동 Undo 기능은 아니다.** 그러므로 빨간 버튼을 눌렀다는 사실만으로 롤백되었다고 판단하지 말고 작업 결과와 모델을 확인한다. 연결 해제·재연결·모델 전환은 기존대로 권한을 회수하며 재연결 후 자동 재허용하지 않는다.

## 구현과 호환성

- UI::Command4개와 UI::Toolbar, Windows용 SVG8개를 사용한다. 색 외에 잠금/연결 모양·체크·비활성·툴팁도 제공한다. 같은 상태에서 매초 아이콘을 다시 로드하지 않는다.
- Panel 제어기는 정보창과 독립적으로 유지된다. 연결 타이머와 ModelIdentity 관찰자는 창을 열지 않아도 동작한다.
- bridge_state.library_jobs와 로컬 emergency_stop 이벤트를 추가한다. 모델을 바꾸는 새 MCP 도구 또는 원격 권한 부여 도구는 추가하지 않았다. 도구 수63개.
- Probe/RBZ를 함께0.13.0으로 업데이트한다. 이전 Probe는 기법 작업 상태/긴급 정지 이벤트를 알지 못하므로 새 RBZ만 설치하면 전체 취소 범위를 보장할 수 없다.
- SVG 아이콘 지원(Windows2016+), Toolbar restore, Command validation은2019 범위에 포함된다. 실제 Windows2019/2020의 동적 아이콘 갱신·도킹·disabled 표시 실기 결과는 아직 없다.

공식 API: [UI::Command](https://ruby.sketchup.com/UI/Command.html), [UI::Toolbar](https://ruby.sketchup.com/UI/Toolbar.html), [UI.refresh_toolbars](https://ruby.sketchup.com/UI.html#refresh_toolbars-class_method).

## 설치 후 화면 확인

1. 0.13.0 EXE/RBZ를 설치하고 SketchUp을 완전히 재시작한다.4버튼 툴바와 닫힌 정보창, 꺼진 연결/권한을 확인한다.
2. 1번으로 연결해 초록 표시,2번으로 실행 허용해 파란 열린 잠금을 확인한다.4번 정보창을 열고 X로 닫아 연결/권한 유지도 확인한다.
3. 20초 시험 작업 또는 충분히 긴 bound 기법 계획에서3번이 활성화되는지 확인한다. 누르면 권한이 회수되고 해당 작업이 중지되는지 결과를 조회한다. 다른 문서의 작업은 유지되어야 한다.
4. 대기 중3번이 비활성인지, 모델 변경과 연결 해제/재연결에서 권한이 회수되는지 확인한다.
5. 툴바를 도킹/숨김 후 재시작해 저장된 배치와 표시 상태를 확인하고 메뉴의 툴바 표시로 복원한다.

자동 검사와 실제 화면 검사는 구분한다. [검증 기록](VALIDATION.md), [시험 배포](TEST_RELEASE.md).
