# VWorld 주변 매스 후속 과제

기록일: 2026-10-30. 사용자 요청에 따른 다음 작업 목록이며, 아래 변경은 아직 구현하지 않았다.

## 목적과 허용 범위

정확한 건물 높이 복원보다 주변 건물의 대략적인 배치와 규모를 단순 기둥형 매스로 확인하는 것이 목적이다. 크게 틀리지 않는 범위의 휴리스틱은 허용한다. 조회값과 추정값의 출처·방법을 기록하고, 위치나 규모가 다른 건물로 잘못 대응되는 것은 줄인다. 현재 결과는 원본 윤곽 59개 중 생성 18동, 높이 0/미제공 34개, 대응 불확실 7개다.

## 1. 높이 0값의 원인 확인

- 사용자 관찰: VWorld 3D 지도에는 해당 위치의 건물이 표시되고 높이도 확인된다. 이 관찰을 WFS 응답과 비교할 재현 사례로 사용한다.
- 현재 조회는 `/ned/wfs/getBldgisSpceWFS`, `dt_d010`의 `hg` 속성이다. `hg=0`은 이 응답 필드의 값이며 VWorld의 모든 데이터에 높이가 없다는 뜻은 아니다.
- 보류된 건물의 PNU·좌표를 기준으로 원시 속성, 파싱 결과, 3D 지도 레이어/건물 식별자, 데이터 갱신시점과 제공 API를 비교한다. 원자료 결측/0, 다른 레이어, 필드 매핑·조회 문제를 구분한다. 원인은 아직 미확정이다.
- 화면에 표시되는 높이가 건물 자체 높이인지, 지붕 또는 클릭 지점의 절대 고도인지, 지면과의 차이인지 확인한다. 고도 기준이 다른 수치를 그대로 압출 높이에 쓰지 않는다.
- 사용할 수 있는 공식 조회 경로를 확인하고, 직접 높이 → 대체 자료 → 층수 등 휴리스틱의 우선순위를 검토한다. 추정 방식과 근거, 단위를 결과별로 남긴다.
- 완료 기준: 대표 0값 사례에서 화면과 API의 차이를 설명하고, 이용 가능한 대체 높이/추정과 계속 보류할 대상을 구분하는 회귀 사례를 확보한다.

## 2. 윤곽 불일치 허용 범위 검토·수정

- 현재 기준: 원본 덮임 45% 이상, IoU 25% 이상, 차순위 IoU가 최상위의 65% 미만. 한 API 건물에 여러 원본 면이 대응하면 보류한다.
- 현재 7개 불확실 사례의 후보별 겹침, 중심 거리, 면적비, 방향, 주소/PNU, 중복 대응 사유를 먼저 기록한다. 허용치만 낮추면 인접 건물의 높이가 잘못 배정될 수 있으므로 실제 사례로 비교한다.
- 정확 매칭과 대략 매칭을 단계화하고 허용치를 설정으로 조절하는 방안을 검토한다. 중심 거리·면적비 등 복합 점수와 분할/합쳐진 윤곽의 대응도 검토 대상이다. 새 수치는 비교 결과로 정한다.
- 높이 결측과 매칭 실패는 별도로 처리한다. 매칭 완화만으로 34개 높이 결측이 해결되지는 않는다.
- 완료 기준: 기존 18동과 보류 7개를 같은 입력으로 재평가하여 추가 대응/잘못 대응/잔여 보류를 비교하고, 매칭 등급과 추정 근거가 남도록 수정한다. 원본 XY 보존과 새 그룹 생성 방식은 유지한다.

## 3. 기법 및 실행 자료 저장 경로 조정

- 현재 기법 소스는 저장소 `techniques/vworld-footprint-scan`, `techniques/vworld-massing`, 등록본과 내보내기는 `%LOCALAPPDATA%/SketchUpCodexMcp/Library` 아래에 있다.
- 실행 설정은 `workflows/suyu-site-50m.json`, 실행 근거는 `dist/vworld-run-*`, 공유 패키지는 `dist/vworld-massing.probe-techpack` 및 `dist/vworld-massing-workflow.zip`이다. `dist`는 Git에서 제외되므로 다른 PC로 소스만 가져오면 실행 근거/패키지가 함께 이동하지 않는다.
- 기법 원본, 사용자 등록본, 프로젝트별 설정/조회 근거, 임시 빌드 파일을 어디에 둘지 검토한다. 출력 경로 설정, 상대경로/한글·공백/OneDrive, 쓰기 권한, PC 이동, 기법 수정본 충돌과 가져오기 절차를 확인한다.
- 모델 PID 경로는 특정 문서에 종속되므로 다른 모델에서 다시 지정하도록 한다. DPAPI 키는 사용자·PC별로 등록하며 소스나 이동용 패키지에 넣지 않는다.
- 완료 기준: 다른 경로/PC에서 기법 등록→조회→계획을 재현할 수 있는 저장·이동 절차와 경로 옵션을 마련한다. 필요한 실행 기록이 빌드 정리로 없어지지 않게 한다.

권장 순서: 0값 사례 조사 → 매칭/높이 추정 정책 비교 → 경로 정책 조정 → 반복 실행과 결과 검증. 현재 구현·사용법은 [VWORLD_MASSING.md](VWORLD_MASSING.md), 실제 검증 범위는 [VALIDATION.md](VALIDATION.md)를 참고한다.
