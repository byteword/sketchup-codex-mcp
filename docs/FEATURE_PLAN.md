# 기본 드로잉·정보조회 구현 순서

## 0.5.0 구현 상태

아래 초기 계획의 지정 객체 상세 조회·사각형·선/폴리라인을 구현했고, 원·프로파일 돌출·회전·축척·그룹·정의 독립화·삭제까지 함께 추가했습니다. 면적/길이는 직접 면·선에 한해 모델 변환을 반영하며 체적과 재귀 집계는 미구현입니다. [실제 도구 계약](BASIC_TOOLKIT.md)을 기준으로 합니다.

사용자가 수동 실기의 시간을 줄이도록 범위를 확장해 요청했으므로, 이제 [고정 일괄 검사](BATCH_TEST.md)와 전용 스킬을 먼저 사용합니다. 자동 회귀 169개 통과, 실제 0.5.0 설치 후 확인은 남아 있습니다. 다음 확장은 이 실기 결과를 확인한 뒤 고급 형상/측정의 범위를 정합니다.

아래는 최초 단계별 계획과 당시 구현 범위입니다.

2026-10-28 기준입니다. 현재 19개 MCP 도구와 시험한 생성·복제·선택·이동·보기 기능을 기반으로, 아래 기능을 한 번에 하나씩 구현합니다. 도구 이름은 구현 전 제안이며 현재 어댑터에서 호출할 수 있다고 안내하지 않습니다.

| 순서 | 기능 | 첫 구현 범위 | 확인 기준 |
|---|---|---|---|
| 0 | 모델 전환 식별 수정 (0.4.1) | New/Open 알림으로 문서 ID 갱신, 실행 허가 회수, 이전 문서 요청 거부 | 같은 Ruby 객체·같은 파일 경로에서도 ID 변경, Save/Save As에는 유지. 회귀 검사 후 실제 설치·전환 확인 |
| 1 | 지정 객체 정보 조회 | 제안 `sketchup_get_entity_info`: 선택을 바꾸지 않고 전체 배치 경로로 그룹/컴포넌트 하나의 이름·태그·직접 재질·잠금·외곽·정의 치수 조회 | 같은 정의의 여러 배치 구분, 오래된 경로/모델 거부, 조회 전후 선택·편집 위치 유지 |
| 2 | 사각형 그리기 | 제안 `sketchup_create_rectangle`: 모델 축 기준 mm 원점, XY/XZ/YZ 평면과 양수 가로·세로. 새 독립 그룹 안에 사각 면 생성 | 치수·면 법선·기본 태그, 현재 편집 변환 보정, 미리보기·한 번 Undo·오류 시 전체 롤백 |
| 3 | 선·폴리라인 그리기 | 제안 `sketchup_create_polyline`: 명시한 모델 축 mm 점들을 새 그룹 안에서 연결. 첫 버전은 면 생성 없이 선만 | 최소 점 수·중복/길이 한도·좌표계 검증, 기존 형상과 병합 없음, 한 번 Undo |
| 4 | 길이·면적·체적 조회 | 앞 단계의 객체/경로 조회를 기반으로 지원 가능한 형상부터 추가 | 단위 mm/mm²/mm³ 명시, 회전·비균등 축척 처리, 비솔리드/지원하지 않는 형상의 결과 의미 구분 |
| 5 | 면 돌출과 추가 기본 형상 | 대상 면·방향·거리 및 닫힌 솔리드 조건을 먼저 합의 | 공유 정의 영향, 중첩 변환, Undo와 실제 앱 회귀를 포함해 범위 확정 후 구현 |

이번 변경은 순서 0의 수정과 작업 스킬 정비입니다. 이후 첫 신규 기능은 순서 1의 지정 객체 조회로 잡습니다. 회전·축척 자체를 원격으로 실행하는 기능이나 파일 열기/저장은 아직 새 명령 범위에 넣지 않습니다.

각 기능은 계약 → 입력 검증/라우팅 → Ruby 실행기 → 필요한 회귀·실제 파이프 검사 → 시험 배포 → 사용자 실기 결과 기록 순서로 진행합니다. 실기를 진행하지 않았다면 자동 검사 통과와 구분해 남깁니다. 코드·배포·GitHub 반영은 그때의 사용자 요청 범위에 맞춥니다.

운영 지침은 [SketchUp MCP 스킬](../skills/sketchup-mcp/SKILL.md), 현재 실제 앱 확인 범위는 [0.4.0 실기 결과](MANUAL_RESULTS_0.4.0.md)에 있습니다.
