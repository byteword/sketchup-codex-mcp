# 빠른 실제 SketchUp 일괄 검사

0.5.0부터 `sketchup_run_self_test`가 고정된 네이티브 API 검사 묶음을 실행합니다. 이전처럼 도형 하나마다 사용자 답변과 Ctrl+Z를 기다리지 않습니다. 시험 모델에서 실행 허가 한 번을 주고 검사 도구를 한 번 호출하면 보고서를 받습니다.

## 사용자 사용 순서

1. GUI·MCP·RBZ를 모두 0.5.0으로 교체하고 재시작합니다. 도구 30개를 확인합니다.
2. 작은 시험 모델을 열고 그룹 내부 편집에서 나옵니다. 패널에서 **MCP 명령 실행 허용**을 누릅니다.
3. “이 시험 모델에서 일괄 실기 검사해줘”라고 요청합니다. [검사 스킬](../skills/sketchup-self-test/SKILL.md)이 대상과 버전을 확인해 검사 한 번을 실행합니다.
4. 통과/실패/생략 항목, 소요 시간, 정리 결과를 확인합니다. 다시 실행하려면 최신 명령 ID가 필요하며 과거 결과 조회를 새 실행으로 취급하지 않습니다.

대상 확인은 실제 세션·모델 ID로 하고 `expected_context=[]`, `confirm_test_model=true`를 명시합니다. root 객체/선택 각각 1000개, 정의 5000개를 넘으면 작은 시험 모델을 사용하도록 거부합니다. 스킬은 현재 요청에서 시험 모델과 검사가 이미 승인됐으면 매 단계 재승인을 요구하지 않습니다. 로컬 실행 허가를 우회하지도 않습니다.

## 한 번에 확인하는 항목

보통 카메라에서는 **기능 24개 + 정리 1개**, 총 25개 결과를 반환합니다.

- 박스·사각형·원·폴리라인 생성, 치수·면적·길이, 전체 경로로 면/선 조회.
- 프로파일 돌출, 모델 축 회전·축척·이동, 그룹 복제.
- 선택·이름/숨김 변경, 잠금 거부와 잠금 해제, 삭제.
- 그룹 묶기·정의 독립화, 회전·비균등 축척한 부모 내부의 면적 조회.
- 위·앞·오른쪽·등각 보기와 객체 확대.
- 임시 도형/정의 제거와 원래 선택·카메라·활성 태그 확인.

두 점 투시 등 지원하지 않는 특수 카메라에서는 화면 검사 5개를 생략하고 결과에 표시합니다. 첫 실패에서 중단하고 나머지는 생략으로 남깁니다. 단계 사이에 **4초의 협력적 시간 예산**을 확인하지만 개별 SketchUp API 호출을 강제로 끊는 제한은 아닙니다. 실제 앱의 속도는 `duration_ms`로 측정하며 아직 실측하지 않은 시간을 성능 결과로 표기하지 않습니다.

## 정리와 검증 범위

검사는 요청자가 고른 기존 객체를 수정하지 않고 자체 생성한 임시 그룹만 조작합니다. 한 외부 operation 안에서 실행기 검증/후조건을 호출한 다음 operation을 **abort**하고, 기존 루트 객체·정의·선택·카메라·활성 태그를 대조합니다. 수정 플래그가 달라지면 별도 실패로 기록합니다. 저장·파일 열기·컨텍스트 이동·임의 Ruby·임의 명령 목록은 실행하지 않습니다.

이 방식은 개별 편집 명령의 operation 경계를 검사 중 생략합니다. 따라서 **개별 명령의 네이티브 Undo, New/Open, 권한 회수, 사용자 편집과의 경합은 이 검사만으로 검증하지 않습니다.** 관련 변경 시 해당 수동 시험만 추가하며, 일상적인 형상 검사마다 다시 요구하지 않습니다. 각 도구의 MCP 스키마/라우팅과 operation 롤백은 별도 자동 회귀에서 검사합니다.

`result.state=completed`여도 `result.data.passed=false`일 수 있습니다. `checks`의 실패 항목을 확인해야 합니다. `cleanup_verified`를 확인할 수 없으면 명령 결과를 `outcome_unknown`으로 남기며 자동 재실행하지 않습니다. 시간 초과도 같은 명령 ID의 결과만 조회합니다.

| 보고서 필드 | 의미 |
|---|---|
| `passed`, `passed_count`, `failed_count`, `skipped_count` | 기능/정리 검사 판정과 집계 |
| `checks` | 각 검사 이름·상태·실패/생략 사유 |
| `duration_ms` | 실제 네이티브 검사 묶음 소요 시간 |
| `cleanup_verified` | 임시 형상 제거와 UI 보존 대조 결과 |
| `modified_before`, `modified_after` | 모델 수정 표시 비교 |
| `individual_undo_tested`, `model_lifecycle_tested` | 이번 묶음에서는 둘 다 false |

## 자동 보고서 실행기

[run_native_tests.py](../skills/sketchup-self-test/scripts/run_native_tests.py)는 같은 단일 검사를 MCP STDIO로 실행하고 JSON을 저장하는 선택적 개발 도우미입니다. 세션·모델·실행 파일 경로와 시험 모델 확인을 명시해야 하며, 실행 파일/중개 앱/확장 버전을 대조합니다. Python 표준 라이브러리만 사용합니다.

이 실행기의 어댑터가 종료되면 기존 소유자 회수 규칙에 따라 해당 실행 허가도 회수될 수 있습니다. 이미 연결된 MCP 도구를 쓸 수 있으면 직접 호출을 우선합니다. 실행기·스킬·개발 의존성은 사용자용 설치 ZIP에 넣지 않습니다.

개발 자동 검사는 `scripts/windows-tests.ps1`로 실행하며 실제 사용자 모델 대신 API 대역과 별도 Win32 시험 파이프를 사용합니다. 단일 검사 스킬을 설치했다고 새 MCP 도구가 자동으로 생기는 것은 아니므로 먼저 0.5.0을 설치해야 합니다.
