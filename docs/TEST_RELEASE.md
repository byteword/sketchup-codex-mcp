# 0.4.0 시험 배포 — 2026-10-28

기본 브랜치 `main`에 기초 명령, 객체 검색·구조 탐색, 박스 생성·복제를 반영한 시험 버전입니다. MCP 도구는 총 19개입니다. 정식 릴리스 전 실제 SketchUp에서 확인할 항목은 [수동 시험](MANUAL_TEST.md)에 있습니다.

## 배포 파일

`dist/sketchup-codex-mcp-0.4.0-test.zip`에는 아래 실행 필수 파일 5개만 포함합니다. 문서·소스·테스트 도우미는 설치 ZIP에 넣지 않습니다.

- `dist/SketchUpMcp.exe`
- `dist/SketchUpMcp.exe.config`
- `dist/SketchUpPipeProbe.exe`
- `dist/SketchUpPipeProbe.exe.config`
- `dist/su_pipe_probe-0.4.0.rbz`

두 EXE의 파일 버전은 `0.4.0.0`, 제품 버전은 `0.4.0`입니다. 파일별 SHA-256은 저장소 루트의 `SHA256SUMS.txt`에 기록합니다. 로컬 빌드와 GitHub Actions의 빌드는 생성 시각 등에 따라 체크섬이 다를 수 있으므로 각 배포본에 맞는 기록을 사용합니다.

## 설치

1. 열려 있는 작업을 저장하고 SketchUp, 중개 GUI, MCP 서버를 종료합니다.
2. ZIP을 풉니다. 기존 MCP 등록 경로를 유지하려면 ZIP 안의 `dist` 폴더에 들어 있는 파일 5개를 현재 실행 파일이 있는 폴더에 복사합니다. 폴더 안에 `dist`를 한 번 더 만드는 일이 없도록 실행 파일 경로를 확인합니다.
3. SketchUp 확장 관리자에서 새 `su_pipe_probe-0.4.0.rbz`를 설치하고 SketchUp을 완전히 종료했다가 다시 엽니다.
4. 새 `SketchUpPipeProbe.exe`를 실행하고 SketchUp 패널에서 연결합니다. 패널 버전 `0.4.0`을 확인합니다.
5. MCP 서버를 다시 시작하고 도구 19개가 노출되는지 확인합니다. 실행 파일 위치가 바뀌었다면 등록된 전체 경로도 수정합니다.

## 첫 시험

복사한 시험 모델 또는 빈 모델에서 진행합니다. 먼저 연결된 PID·모델 경로를 조회해 정확한 대상을 확인합니다. 정보 조회·검색에는 실행 허가가 필요하지 않습니다.

변경은 SketchUp 패널의 **MCP 명령 실행 허용**을 누른 뒤 요청합니다. 미리보기와 실제 실행은 각각 최신 상태의 새 `next_command_id`를 사용하며, 현재 편집 경로도 다시 확인합니다.

- “이름에 기둥이 들어간 그룹과 컴포넌트를 찾아줘.”
- “모델 원점에 가로 6000, 세로 12000, 높이 3000 mm인 A동 박스를 만드는 미리보기를 보여줘.”
- “새 명령 ID로 그 박스를 만들어줘.”
- “생성한 박스를 모델 X 방향으로 10000 mm 떨어진 곳에 하나 복제해줘.”
- “생성한 객체들의 이름과 크기를 읽어서 확인해줘.”

속성·이동·생성·복제는 요청당 하나의 Undo 작업으로 묶습니다. SketchUp에서 Ctrl+Z로 요청 전체가 되돌아가는지 확인합니다. 선택·카메라 변경은 모델 Undo와 별개입니다. 잠긴 객체나 여러 배치가 공유하는 편집 상위 정의 등 지원하지 않는 대상은 거부합니다.

시간 초과 시 변경을 자동 재전송하지 않고 `sketchup_get_command_result`로 결과를 조회합니다. 같은 ID의 결과는 과거 실행 기록입니다. 사용자가 Undo한 뒤에도 이전 성공 기록이 남으므로, 같은 ID를 보내 재생성하거나 다시 이동시키지 않습니다.

## 검증의 범위

자동 검사는 실제 Windows 통신 경로를 사용하지만 모델·형상·카메라·Undo에는 테스트 대역을 사용합니다. 배포 준비 이후 사용자가 새 시험 모델에서 생성·복제·이름 변경·이동과 Undo를 확인했고, 중첩 이동·잠금·허가 회수도 실제 앱에서 시험했습니다. 선택·확대·보기 전환의 API 확인과 남은 조건까지 [실기 결과](MANUAL_RESULTS_0.4.0.md)에 구분했습니다. 배포 준비 당시의 자동 검사와 이후 사용자 참여 실기는 별도 기록입니다.
