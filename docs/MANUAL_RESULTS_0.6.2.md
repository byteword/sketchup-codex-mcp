## 일괄 변경과 Undo

- 새 박스 생성 뒤 이미 삭제한 시험 대상의 이동을 같은 batch에 넣었습니다. 두 번째 단계는 entity_not_found로 거부됐고, 첫 박스도 취소되어 루트 개수와 검사 직전 외곽이 유지됐습니다.
- 그 후 새 batch의 독립 단계2개로 X=20m·22m에 박스2개를 생성했습니다. 요청 성공, 루트 객체1→3, UI 갱신 경고0을 확인했습니다.
- 사용자가 **Ctrl+Z를 정확히 한 번** 눌렀다고 확인했습니다. 후속 조회에서 두 생성 PID 모두 stale이고 루트 객체1개·정의1개로 복귀했습니다. 일괄 요청 전체가 Undo 한 번에 제거됐음을 확인했습니다.
- Undo 뒤 기존 인물의 모델 외곽 수치가 이전과 달랐습니다. Face Me 인물의 카메라 의존 외곽/캐시 또는 사용자 화면 조작 영향은 별도 확인 대상이며, 이번 결과를 원본 모델 전체 외곽 불변까지 인증한 것으로 해석하지 않습니다.

## 종료 상태와 다음 작업

시험 형상·재질·태그·장면을 정리했고 최종 루트는 기존 컴포넌트1개, 태그1·재질8·정의1·장면0·선택0입니다. 단독 명령들은 commit됐으므로 **modified=true와 Undo 이력이 남습니다.** 파일을 저장하거나 수정 플래그/이력을 강제로 초기화하지 않았습니다.

0.6.3은 해제 결과를 유효한 직접 Drawingelement와 양의 PID로 제한하고 중복을 제거합니다. 경로 제한/개수도 필터 후 계산합니다. 점/꼭짓점 이동은 native Length를 Float로 바꿔 후속 좌표를 판정합니다. 신규 회귀5개와 전체229개 자동 검사가 통과했지만 **0.6.3 설치 후 전체56항목은 아직 미실행**입니다. Outliner CPU·defer/normal 비교, 깊은 중첩/특수 카메라·수명주기/경합 조건도 별도입니다.
