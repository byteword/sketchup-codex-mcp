지점·작은 범위 지형 높이 조회

VWorld 지형 타일에서 좌표별 높이를 보간해 숫자와 CSV로 확인합니다.

한 점: 경도,위도
범위: 서쪽경도,남쪽위도,동쪽경도,북쪽위도 (각 방향 최대 0.02도) 브라우저 화면에는 키를 별도로 입력합니다. 이 파일은 키를 저장하지 않으며 VWorld 공식 SDK가 메모리에서 사용합니다. Probe의 암호화 저장소를 브라우저에 공개하지 않습니다.
3D 지도 API 사용 권한이 있는 키로 시작하세요.
SDK 반환 높이는 타원체 기준입니다. VWorld 원자료의 수직 기준·변환은 별도 검증 전이므로 확정된 해발 표고로 사용하지 마세요. 건물 지붕과 카메라 고도는 사용하지 않습니다. 단계 14를 기본으로 사용합니다. 높은 단계가 항상 제공되는 것은 아닙니다. 누락값은 0으로 바꾸지 않습니다. 지도를 클릭하면 그 좌표의 지형 높이를 같은 방식으로 조회합니다. VWorld 공식 SDK 예제
